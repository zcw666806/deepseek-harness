# @deepseek-ai/dsh-client-ui-capabilities

[English](README.md) | 中文

## 概述

能力管理设置页显示已配置的引擎、当前健康状态、缺失依赖与可用管理动作。用户无需提供可执行命令，即可检查、准备、启动或停止能力。

<a id="use-this-package"></a>
## 使用本包

将本浏览器功能与capability-manager Host及现有设置外壳一起挂载。打开设置→能力管理，检查报告与依赖条件。Host提供受支持的动作；请求执行时禁用其他动作，并允许用户取消。本设置页不会停止由外部管理的本地服务。

导出能力配置会下载JSON清单。恢复能力配置会校验选中的JSON文件，并预览提供方身份、版本兼容性、当前依赖及配置是否仍需校验。用户明确选择应用配置后才请求恢复，然后刷新报告并列出已恢复、缺失、不支持或失败的结果。兼容不代表引擎或模型已经就绪。恢复不会准备或启动引擎，也不会下载模型；缺少提供方和版本不匹配会明确保留。

视频工作流提供方挂载后，设置→视频工作流可以编辑服务地址、目标名称、API格式模板JSON，以及提示词、时长、尺寸、参考图和输出映射。校验不会丢弃草稿；保存会持久化禁用状态的配置。保存后需单独启用工作流。请求失败会保留草稿。界面不显示请求头的值，也不会安装模型或启动引擎。黑帧传输诊断模板明确标为非AI，只添加到草稿，仍需保存和启用。配置冲突后，可选择重新读取并放弃草稿，以取得当前Host版本。

本功能没有插件专属配置。引擎就绪不代表已经安装视频模型或生成工作流；每个提供方负责报告自己的依赖条件。

<a id="understand-the-implementation"></a>
## 理解实现

浏览器使用全局挂载的能力Remote，并为能力管理和可选工作流提供方贡献根作用域的`settings.section`入口。控制器通过注入的框架hook发布Host报告，管理取消和下载URL，拒绝重连后的迟到结果，并在卸载时等待未完成请求结束；进程归属与依赖校验由Host负责。

<a id="model-experience"></a>
## 模型体验

### 能力设置

#### 模型看到什么

本 UI 不注册模型工具或提示词分节，也不发送模型消息。对 `capabilities.perform` 和 `capabilities.restoreManifest` 的调用属于 Host 管理操作。报告和恢复结果保留为 UI 状态；配置变化对后续模型可见内容的影响由消费该配置的提供方负责。

#### Token 影响

本 UI 直接增加的模型请求 token 为零。查看能力、下载配置和调用 Host 管理操作不会追加对话消息。

#### KV Cache 影响

能力查看状态与配置下载不改写对话历史或进行中的请求。恢复提供方配置可能影响后续请求；产生的上下文与缓存行为由该提供方负责。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **报告按请求更新。** 刷新或执行动作，才能检查设置页之外发生的变化。
- **恢复由提供方决定。** 清单不能安装缺失的提供方，也不能补充提供方尚未具备的模型。
- **JSON下载使用内存缓冲。** 浏览器保留完整清单，直到下载URL被释放。
