# @deepseek-ai/dsh-client-ui-video-production

[English](README.md) | 中文

## 概述

本浏览器插件在[视频制作服务](../../video/video-production/README.zh.md)之上提供视频创作工作台。每个会话拥有一个持久项目。工作台编辑镜头描述、生成参数、参考素材关联、采用版本与成片顺序，无需改变 agent 循环。

## 使用本包

在 Web profile 中将本插件与视频制作 Host 控制器一起挂载。在输入框选择**视频创作**，让规划模型编写项目分镜。点击回复下方的**打开分镜画布**，即可在当前对话中编辑 `storyboard.md` 导入的镜头。首次打开会导入镜头标题、时长、生成提示词、画幅和分辨率。再次打开会读取已保存的画布，包括镜头编辑和已生成的片段。可在画布的素材库上传参考图，再关联到所选生成器支持的镜头。

画布分为参考图、分镜描述、生成、已录制视频、编排和最终成片。将图片端口连接到生成节点的参考图端口，即可关联素材；将已完成视频端口连接到编排节点，即可采用版本。检查器按生成顺序列出已连接参考图；箭头按钮调整同一镜头输入的顺序，保存分镜后生效。参考连接从对应描述卡下方绕行，并跟随其坐标。删除这些连接会移除对应关联或采用关系。描述到生成、生成到版本的连接固定不变。连接与检查器编辑在保存分镜前均为草稿；生成和导出要求先保存。平移、缩放、选择、搜索与节点排列使用逐会话查看状态。素材库可折叠且保留上传字段；已有项目默认收起素材库，仅选择镜头时显示检查器。查看偏好使用独立于 Host 项目的版本化浏览器存储键。没有已保存视口时，大图以可读缩放聚焦已选节点或首镜头；适应画布可查看全图。顺序条调整持久化成片顺序，与节点坐标无关。

生成目标选择器仅用于接下来单镜头或批量操作，独立于已保存的分镜字段。它只列出 Host 提供的目标；有多个目标时必须选择，所选目标消失时必须重选。已声明的输入限制会禁用不受支持的请求。每个镜头保留生成尝试及其录制的描述、参数、有序参考图、生成器身份和模型；没有来源信息的记录会明确标为未记录。修改输入会标记旧结果；修改采用版本或顺序会将已导出成片标为待更新。成片列出其录制的输入版本。生成缺失镜头会启动持久化的 Host 后台批次，并跳过已有成功视频的镜头。关闭页面只停止观察，批次继续运行。暂停及取消会等待当前镜头结束，再停止后续工作；Host 重启后明确继续时仅提交尚未提交的镜头。未确认的提交需要核对，不会自动重试。批次观察使用可配置的 batchPollIntervalMs 间隔。媒体按需加载到带下载链接的原生视频播放器。合成导出要求每个已保存镜头均采用成功视频；Host 配置决定导出能力是否可用。成片卡将最近导出尝试的状态与保留的上次成功成片分开显示。

导出项目包按有界分块传输已保存的项目与素材，并提供本地下载。无需调用模型即可恢复：选择工作区，新建会话后直接打开**视频创作**，不发送消息。恢复项目与素材仅接受空的当前会话，不覆盖其他项目。上传和下载报告字节进度，并可取消。恢复后保留生成能力需求；恢复能力配置是独立的显式动作，仅应用声明式设置，不安装或启动引擎。浏览器将下载分块组装为完整Blob后保存。

成功的 `generate_video` 工具结果也提供内联视频预览和下载，无需先创建制作项目。会话日志负责授权这些媒体读取；失败结果与格式不合法的元数据保留其文本结果，不提供预览。

输入框的视频创作控件列出已为该工具配置的原生视频模型。明确选中的模型用于同一会话后续工具调用。只有一个已配置模型时，默认显示该模型。

<a id="understand-the-implementation"></a>
## 理解实现

插件挂载其生成的 Remote 命名空间，并在 `studio` 注册视频工作台。逐会话控制器通过注入的框架 hook 发布项目与操作快照。组件仅接收本地化文案、回调和声明的画布 store；组件不会接收 Cordis Context，也不会订阅外部数据源。

媒体读取由 Host 项目授权，并以有界字节片段获取。浏览器合并重复读取、检查字节偏移是否推进，并为每个附件创建一个 Blob URL。重连会撤销这些 URL，并阻止旧请求向新连接发布结果。插件卸载先等待操作、媒体读取与传输清理完成，再撤销 URL 并卸载其 Remote 命名空间。

Host项目目录保留没有聊天消息的会话中的已保存项目标题。它每批查询最多256个会话身份，从已提交的项目响应更新，并在重连后重建。工作区呈现贡献让这些项目可见、可搜索，不修改对话元数据。

本功能加载后，会阻止新会话复用已有已保存项目或正在执行项目操作的会话；其他候选会话通过Host项目查询确认。它不会为标记项目使用而创建聊天消息。

编辑会暂存带修订号检查的草稿。生成、排序和导出要求先保存，因此可见草稿不会意外地使用不同的 Host 值生成视频。服务端修订冲突时保留草稿，并提供刷新入口。

<a id="model-experience"></a>
## 模型体验

通过视频制作服务面向模型的工具间接影响模型；工作台不添加提示词章节或工具 schema。

#### KV Cache 影响

画布查看设置不影响模型上下文。项目编辑仅在后续已记录的工具操作读取时进入模型上下文。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- **镜头剪辑通过检查器编辑。** 裁切起止点、原声音量和定时字面字幕在成片导出时应用，源视频保持不变。完整多轨时间线、转场、波形编辑、语音合成和配乐混音仍属于独立能力。
- **播放会缓冲一个请求的媒体对象。** 传输按片段进行，浏览器在播放前组装完整对象；不会直接流式播放 Host 文件系统中的视频。
- **项目更新通过请求读取。** 刷新可读取另一个客户端的修改；本包不订阅项目变更流。
