# @deepseek-ai/dsh-capability-manager

[English](README.md) | 中文

## 概述

`ctx.capabilities` 是 DSH 已安装能力的共享目录。提供方贡献描述、前置条件检查及固定的准备、启动和停止回调。管理界面读取同一目录并调用这些回调，不接受任意进程命令。可迁移清单携带引擎要求及所属提供方明确导出的配置。

## 使用本包

通过 `dsh` profile 将本服务与贡献能力的提供方共同挂载。每个已安装提供方调用 `register`，提供稳定的品牌化能力标识、引擎标识、公开描述及 `inspect`。可选生命周期回调决定可用操作。注册返回异步释放函数；提供方卸载时先等待其完成，再释放进行中的管理操作仍可能使用的运行资源。

`list` 检查全部当前提供方，不准备或启动它们。`perform` 接受一个已注册标识，以及 `check`、`prepare`、`start` 或 `stop` 之一。缺少提供方或不支持的操作会在调用回调前拒绝。提供方异常成为通用错误观察结果，原始异常细节不进入管理响应。提供方通过检查结果返回安全且可操作的诊断与前置条件，必须从这些观察结果中排除凭据和可执行配置。

### 可迁移配置

`exportManifest` 生成格式为 `dsh-capabilities`、版本为 `1` 的清单，并为每个当前提供方保存一项要求：能力标识、引擎标识、可选引擎版本及可选的提供方声明 JSON 配置。没有 `exportConfiguration` 的提供方仅贡献要求。提供方负责在导出配置前移除凭据、本机路径和其他机器绑定。

`planRestore` 在检查目标提供方前验证完整清单。它报告缺失提供方、不兼容的引擎或版本、当前前置条件及可用操作，不应用配置。`compatible` 表示已安装提供方接受该引擎标识及恢复操作；导入设置在明确恢复前仍是 `pending-validation`。预览不返回导入配置值，也不准备或启动引擎。

`restoreManifest` 在调用任何提供方前验证完整 JSON 声明及唯一标识。缺少提供方时返回 `missing`。引擎或声明版本不同时返回 `unsupported`；提供方没有恢复回调而清单包含配置时也如此。匹配配置交给 `restoreConfiguration`，该回调验证并提交自身完整更新。即使另一个提供方拒绝配置，各独立提供方仍可恢复成功。返回的 `restored` 表示配置已接受；运行就绪状态由 `list` 独立报告。

恢复清单不会安装插件、准备环境或启动运行时；这些仍是明确的固定操作。项目迁移代码复用 `./portable` 导出的 `parsePortableCapabilityManifest`，无需维护另一份 schema。解析器负责格式、字段、JSON 值及重复标识验证；迁移所属实现应用完整包的字节与条目限制。

### 配置

`maxProviders` 限制已注册目录及恢复清单的数量。`checkTimeoutMs` 限制检查时长，包括等待先前操作的排队时间。`actionTimeoutMs` 限制准备、启动、停止及配置恢复时长，包括排队和操作后的检查。`maxResultBytes` 限制完整 UTF-8 JSON 结果或导入清单，包含封装及所有提供方描述。生成的[配置目录](../../../docs/config-catalog.zh.md)拥有准确默认值与范围。

<a id="understand-the-implementation"></a>
## 理解实现

每个提供方注册拥有取消控制器及一个操作尾部。同一标识的调用串行执行，不同能力可独立推进。调用方取消或配置截止时间会通知进行中的提供方，操作仅在回调结束后返回。提供方必须响应取消，并在返回前等待自己拥有的进程或请求结束。管理器不直接终止进程。

注销立即移除可见标识，取消排队与进行中的操作，并等待它们结束。同标识的替代注册拥有独立生命周期；旧注册的退出不会移除替代者。服务卸载停止接纳操作并等待剩余注册结束。本服务不持久保存进程句柄、本机配置或能力目录；已安装提供方插件负责重建目录。

## 模型体验

### 管理结果

#### 模型看到什么

本服务不注册模型工具或提示词分节。管理操作返回 `CapabilityView` 观察结果，以及包含提供方声明配置与引擎要求的 `PortableCapabilityManifest`。只有调用它们的代码工具将结果纳入已记录输出时，这些值才进入模型上下文；展示和会话记录由该工具负责。直接 UI 管理不创建模型消息。

#### Token 影响

本服务直接增加的请求前缀 token 为零。调用方代码工具可将返回的管理数据追加到历史；`maxResultBytes` 限制每个完整服务结果，代码工具负责自身模型输出限制。

#### KV Cache 影响

目录读取与管理操作不改写模型历史或进行中的请求。已记录代码工具结果通过该工具的普通输出追加。各提供方负责恢复配置对后续请求的影响。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **可用能力由已安装提供方定义**——迁移清单报告缺失提供方与版本，不从导入数据获取或执行安装指令。
- **取消依赖提供方配合**——截止时间通知取消，管理器等待操作结束；不响应取消的回调可能延迟调用方及卸载。
- **恢复按提供方保持原子性**——不提供跨提供方事务，也不会在另一个提供方已接受配置后回滚。
- **可迁移配置不包含运行时载荷**——提供方及迁移所属实现处理模型文件、环境重建、附件数据和本机凭据绑定。
