# @deepseek-ai/dsh-video-production

[English](README.md) | 中文

## 概述

`dsh-video-production` 为每个已存在的会话拥有一个持久视频项目。项目包含可复用的角色、场景和道具图片、有顺序的分镜、生成尝试、选用的视频版本及成片导出。Web 视频制作视图与 `video_project` 工具使用同一份状态。生成提供方交付持久视频附件；本包负责项目编辑、尝试历史、媒体授权和基于宿主 FFmpeg 的本地导出。

## 使用本包

Web 组合在既有附件、storage-domain、会话持久化与工具服务旁挂载本服务。自定义组合挂载相同能力及一个视频生成提供方。项目读取不会创建或恢复 Agent。版本为零的视图代表已存在的会话尚无已保存项目；首次更新持久保存标题、素材和分镜。

`projectSummaries` 为每次最多 256 个不同会话标识提供只读展示索引。结果只包含与当前会话生命周期相符的已保存项目，返回项目标识、修订号及最多 160 个 Unicode 码点的显示标题。完整标题和项目仍通过 `view` 读取。不存在或已删除的会话、过期生命周期的记录会被省略；其他持久化错误仍拒绝请求。查询不创建或物化会话，也不调用模型。侧栏可借此保留只有项目的会话，无需改变空对话的含义，也不会把项目职责移入会话数据。

### 编辑与生成

`importWorkspaceStoryboard` 打开会话已保存的项目，或从其工作区内 UTF-8 编码的 `storyboard.md` 初始化项目。导入读取标题和有序的镜头小节，最多读取 `maxProjectBytes` 字节，要求镜头包含有效时长和提示词或画面描述。并发请求沿用最先保存的项目。Markdown 是初次导入的源文档，生成视频需要另行操作。

`update` 根据 `view` 返回的版本号替换可编辑项目字段。稳定的镜头标识保留完整尝试历史。镜头通过标识选用已完成版本；`reorder` 接受当前镜头标识的完整排列。参考图必须属于本项目，或已经作为准入后的图片出现在此会话中。`addAsset` 准入上传的光栅图片，并在存储成功后追加素材。

`generate` 追加一次尝试并等待选中的提供方。各镜头按 `assetIds` 顺序传递素材图片；选中没有图片的素材会在调用提供方前失败。项目后续编辑后，尝试仍保留原提示词、时长、画面比例、分辨率及有序参考图片。成功尝试成为选用版本。失败和取消保留尝试记录，重试会创建另一个版本。每会话的变更队列防止重叠操作覆盖彼此的结果。UI 批量操作使用 `onlyIfMissing` 在队列内重新检查当前镜头，已有已完成视频版本时跳过生成，也涵盖请求等待期间另一调用方已经完成的情况。普通生成和重试仍创建新版本。读取可以观察到进行中的尝试。

`generationTargets` 列出提供方当前声明的生成器与模型组合、名称、配置修订及输入限制，不联系模型。生成要求恰好匹配一个当前目标，并在创建尝试前拒绝不支持的设置。每次新尝试在输入旁冻结所选生成器标识、名称及可用的配置修订。历史尝试可能缺少生成器标识、名称或配置修订。

`conversationGenerationTargets` 列出 `generate_video` 可用的原生视频模型。明确选中的模型以当前会话生命周期为范围保存，与制作项目的生成目标独立。配置移除已保存的模型时，请重新选择当前可用的模型再生成。

### 宿主拥有的生产批次

`startBatch` 先保存缺失镜头批次，再开始生成；关闭浏览器页面不会停止批次。`batch` 与 `listBatches` 读取持久进度。每个会话保留一个当前批次。`pauseBatch` 与 `cancelBatch` 在下一个镜头边界停止：`pausing` 与 `cancelling` 表示当前提供方请求仍可能完成并产生费用。已完成的视频保留在项目中。控制操作要求提供观察到的批次标识，替换后的会话生命周期不能继承原批次。

宿主重启后，没有批次会自动提交任务。`resumeBatch` 核对冻结的生成输入、有序参考图、提供方配置修订及保留的已完成结果后，仅继续尚未尝试的镜头。输入变化或已完成结果缺失时需要核对。没有记录结果的检查点变为 `uncertain`，也包括预留提交后、联系提供方前崩溃的情况。继续批次永不重试未确认镜头；显式请求再次单镜头生成前，应核对提供方结果。批次描述属于项目数据，不是可序列化的 `ctx.jobs` 回调，也不包含在可移植项目包内。

### 导出与媒体

已采用镜头可保留可选的非破坏性 `edit` 值：相对于源视频的 `trimStartSeconds` 和 `trimEndSeconds`、0 到 4 的原声 `volume`，以及按时间显示的字面字幕。字幕时间相对于裁切后的镜头；0 静音，1 保留原音量。保存编辑不改变源附件和生成历史。每次导出在源版本标识旁保存对齐的 `clipEdits`。渲染器同步裁切画面和音轨，并从私有 UTF-8 文件读取字幕文本，禁用表达式展开。`maxCaptionsPerShot` 限制字幕记录数；可选的 `subtitleFontPath` 指定复制到私有渲染目录的宿主字体。

`export` 按项目顺序拼接每个镜头选用的已完成版本。FFmpeg 与 ffprobe 必须已安装在宿主执行环境中；`ffmpegPath` 和 `ffprobePath` 选择其可执行程序。渲染器将各片段统一为配置的尺寸和帧率，保留已有音轨，补齐较短音轨，并为无音轨片段补充静音。导出的 MP4 成为持久附件。缺少程序或执行环境不兼容会保留失败的导出及可操作诊断；服务不会安装任何程序。

`readMedia` 要求会话标识、项目标识及项目当前引用的附件。它返回规范元数据和按原始字节偏移定位的 base64 片段。每个请求最多读取 256 KiB；客户端可用 `nextOffset` 与 `totalBytes` 组装浏览器预览或下载，无需接收宿主路径或提供方凭据。

### 可移植项目包

`prepareProjectExport` 将当前项目及其引用的图片、视频字节冻结为 `project.dshvideo` 下载文件。带版本的二进制容器先保存有上限的 JSON 清单，再保存原始媒体帧；共享附件标识只保存一次。它保留素材、镜头顺序、冻结的生成输入、已采用版本、历史成片及记录的生成器与工作流要求。包中不含源会话标识、项目标识、修订号、执行诊断、可执行文件路径、凭据或会话记录。用户编写的提示词和描述仍属于项目内容。挂载可选能力管理器时，项目随附其明确导出的可移植配置清单，不包含模型权重或运行环境。

下载与上传使用会话拥有的传输标识和原始字节偏移。`readProjectTransfer` 每次最多读取 256 KiB；`writeProjectTransfer` 只接受准确下一偏移位置的规范 base64 编码。上传在写入前声明完整大小。`commitProjectImport` 要求已收到全部字节，校验格式、严格记录 schema、引用关系、媒体帧长度与 SHA-256 哈希，经目标附件存储准入媒体后，一次提交完整项目。目标必须是已存在且没有已保存项目的会话，也会在上传开始后变更时重新检查。目标身份与生命周期替换源身份。运行中的尝试转为已中断，已选用的完成版本保持选中，历史成片的源版本标识可以在镜头删除后保留。

导入结果返回声明式生成要求及可移植能力配置，由用户明确通过能力管理器恢复。导入不会安装依赖、启动引擎、调用模型或恢复机器相关的密钥。准入失败可能留下未引用附件，但不会留下半个恢复项目。传输拥有者串行执行并发写入、读取、提交与取消。`cancelProjectTransfer` 删除私有文件，对已消费或不存在的传输无操作；其他会话拥有的现存传输仍会被拒绝。

项目包默认上限为完整容器 768 MiB、清单 4 MiB、四个保留传输，以及 30 分钟传输有效期。对应配置字段是 `maxProjectPackageBytes`、`maxProjectPackageManifestBytes`、`maxProjectTransfers` 和 `projectTransferTimeoutMs`。完整包检查包含清单与媒体，所有操作均不公开临时宿主路径。传输文件会过期、随服务卸载消失，并且不在重启后续传；用户下载的项目包是可移植恢复文件。媒体分帧与哈希使用有界缓冲，但附件准入可能在配置的项目包上限内持有一份完整图片或片段。

### 配置

生成的[配置目录](../../../docs/config-catalog.zh.md)说明所有字段。项目默认允许 64 个镜头、64 个素材、每镜头 20 次尝试、20 次导出和 1 MiB 序列化项目数据。生成与导出各有五分钟截止时间。成片默认输出为 1280×720、每秒 24 帧，源片段及输出大小上限为 512 MiB。部署差异通过显式插件配置改变。

```yaml
- id: video-production
  name: '@deepseek-ai/dsh-video-production'
  config:
    ffmpegPath: ffmpeg
    ffprobePath: ffprobe
    generationTimeoutMs: 300000
    exportTimeoutMs: 300000
```

## 理解实现

<details>
<summary>实现细节——点击展开</summary>

`video_production` 存储域为每个会话保存一个带版本的项目，并将其绑定到该会话的创建时间。写入先等待会话物化，再提交旁车数据。复用会话标识不能继承另一个生命周期的项目，长操作也不能提交到替换后的会话。服务启动时，被进程终止遗留为进行中的尝试会成为已中断。卸载停止接纳变更，取消进行中的工作，等待每项操作，然后关闭存储域。

`registerGenerator` 贡献一个具名、响应取消的提供方并返回其释放函数。可选的描述回调提供当前可选配置；省略时公开一个未声明限制的具名路由。提供方接收解析后的提示词、时长、画面比例、分辨率、选中的参考图片和可选模型标识。返回值是持久附件，而非提供方下载地址。服务在记录成功前验证已存储字节。模型工具通过普通工具输出记录完整返回项目；直接 UI 编辑仅在后续工具读取项目时才进入模型可见内容。

服务在启动付费生成或导出前，预留保存有界失败信息所需的项目空间。过大的终态元数据或诊断会成为失败尝试，避免项目一直显示进行中。存储 I/O 错误仍作为基础设施错误报告。FFmpeg 进程使用受管理的子进程服务、固定参数数组、移除 `FFREPORT` 后的清理环境、私有临时文件及等待到进程树退出的清理。输入解复用器固定为 MP4 或 WebM，协议限定为本地文件与管道。视频 `fps` 滤镜建立配置的帧率，归一化画面从零时间戳开始且只编码一次。实测画面时长限制独立封装操作中的音轨裁剪或补齐，该操作复制已编码画面。

</details>

## 模型体验

### 项目工具

#### 模型看到什么

[`video_project` 工具目录](../../../docs/tool-catalog.zh.md#deepseek-aidsh-video-production)拥有动作与参数说明。每次成功操作以 JSON 返回完整当前项目，包括参考图元数据、镜头提示词、有序尝试、选用附件及导出结果。结果中不包含视频或图片字节。

#### Token 影响

挂载此插件时，工具 schema 贡献固定请求前缀。每次调用追加完整项目结果；`maxProjectBytes` 限制每个单独结果，但保留历史中可以包含多个项目版本。

#### KV Cache 影响

插件生命周期内 schema 保持稳定，项目结果追加到历史。编辑项目不会改写既有模型消息；后续工具结果引入更新状态。调用模型的提供方负责缓存可用性与逐出。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **一个项目属于一个会话**——项目包可恢复到新的空目标会话；不提供实时共享或会话分叉时的项目继承。
- **单次生成与导出调用等待完成**——生产批次在页面关闭后继续运行并保留重启检查点，但未确认的提交永不自动重试，单次调用在重启后不会续跑。
- **导出要求宿主本地的 FFmpeg 与 ffprobe**——无法访问宿主临时文件的远程执行环境会被拒绝；不捆绑或安装任何可执行程序。
- **成片编辑以采用片段为单位**——支持裁切、原声音量及定时字面字幕；转场、语音合成、配乐混音与自动对白对齐需要独立操作。
- **参考一致性取决于配置的提供方**——本包组织参考图并保留其顺序，但不生成参考图，也不保证角色身份一致。
- **视频输入与原生编辑是独立操作**——本项目工作流不提供上传视频作为模型输入、提供方原生视频编辑或视频续写。
