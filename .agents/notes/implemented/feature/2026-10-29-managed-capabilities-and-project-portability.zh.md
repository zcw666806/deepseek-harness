# Agent Note: 托管能力与制作项目迁移

Status: implemented

[English](2026-10-29-managed-capabilities-and-project-portability.md) | 中文

## 问题

制作项目不仅依赖画布：模型路由、工作流定义、本地执行环境和持久媒体在迁移到其他机器时必须保持明确区分。导入项目包不能获得选择宿主执行命令、替换凭据或终止无关进程的权限。

## 决策

[能力管理器](../../../../packages/capability/capability-manager/README.zh.md)拥有由 effect 管理的目录和固定管理操作。已安装提供方贡献实际检查及生命周期回调。每个提供方的操作串行执行，不同提供方可以独立推进。移除时关闭接纳、取消排队及进行中的工作，并等待完成，再让替代注册拥有后续操作。[能力设置界面](../../../../packages/client/ui-capabilities/README.zh.md)通过全局 Remote 组合消费这些操作，不依赖其他功能视图是否挂载。

已有空 Session 可以选择已注册的非 Chat 视图，无需发送提示词。会话外壳、标题和正文共享一个 Session-store 轴，包括 session-maybe 声明。没有 Session 时，渲染器提供身份稳定的冻结初始快照及调用即抛错的操作，不创建持久实例，也不读取无 Session 后缀的存储键。root 作用域不能共享该句柄。默认 Chat 保留欢迎页，选择非 Chat 视图只改变呈现，不伪造对话活动。这细化了 [slot 权限决策](../architecture/2026-07-22-slot-type-chain-implementation.zh.md)，仍保持每个句柄及 Session 只有一个实例。

工作区导航分别判断 Session 是否已有项目，以及是否没有对话记录。领域拥有者贡献与释放周期绑定的复用检查及呈现源。视频目录从 Host 读取有界已保存项目摘要，在重连后重建投影，并应用已提交项目的返回值。项目无需伪造对话轮次，也能保留侧栏标题、搜索入口和导航访问。复用检查拒绝已有项目及进行中的变更，Core Session 状态保持不变。会话重命名及对话分叉仍与项目标题编辑和项目包恢复分开。

[托管 ComfyUI 运行环境](../../../../packages/video/video-comfyui-runtime/README.zh.md)将已审查产物标识和本机绑定保留在可迁移项目数据之外。准备时验证离线缓存、重建匹配的私有环境，并检查已安装文件。启动使用有界且核对版本的本地就绪检查和受管理子进程服务；取消和卸载等待进程树退出。可以连接已运行服务，但不接管或终止它。工作流提供方可在生成前请求此能力，其他生成器仍可使用不同引擎。

可迁移能力清单包含提供方与引擎标识、可选版本，以及提供方拥有的声明式配置。恢复先验证整个清单结构，再报告各项缺失、不支持、失败或已恢复状态。提供方在提交前验证其完整配置。[工作流控制决策](2026-11-03-production-workflow-controls-and-durable-batches.zh.md)在明确恢复配置前提供只读的目标兼容性预览。恢复不会准备或启动引擎。ComfyUI 工作流以禁用状态恢复，并排除操作输入、传输凭据及机器路径。设置解析在 Schemastery 规范化前复制不可变快照。pi-ai 贡献通过既有命名空间恢复模型定义，保留目标机绑定和凭据引用，不导出凭据值或刷新 OAuth。

[视频项目拥有者](../../../../packages/video/video-production/README.zh.md)导出包含有界清单和去重原始媒体的版本化二进制容器。每段长度、哈希及项目关系均在附件准入前验证。恢复要求目标 Session 已存在且项目为空，在变更队列中复核生命周期，将媒体重映射为目标规范附件，再一次提交完整项目。运行中尝试成为已中断，不会重新提交。历史成片保留源版本标识，即使对应镜头已经删除。可选能力清单返回后由用户明确恢复，不纳入项目原子提交。

传输票据是临时且绑定 Session 的。读取、写入、提交、过期和取消共用串行传输所有权；票据不存在时取消幂等，仍存活的其他 Session 票据会被拒绝。UI 控制器在释放期间保留待清理操作，在撤销传输前等待已知票据取消，同时让重连代次保持独立。对断连且响应丢失的客户端，票据过期仍提供有界兜底。

## 考虑过的替代方案

**将引擎运行环境合并进助手进程。** 提供方标识和进程所有权可以提供统一产品入口，无需将 DSH 绑定到特定推理框架、Python 环境或模型家族。

**将虚拟环境作为项目状态复制。** 解释器位置、原生 wheel 和硬件支持属于目标机器。已审查产物缓存可以重建环境，项目媒体和声明式设置独立迁移。

**恢复宿主命令或自动启用导入工作流。** 项目包携带数据和需求。已安装提供方保留准备、启动及凭据绑定的权限，恢复后的工作流配置需要明确启用。

**导入时替换已有目标项目。** 空目标接纳以及最终生命周期、修订复核保留现有工作，让单次项目提交有明确拥有者。

## 影响

作者从 DSH 管理已安装能力及项目恢复。首批提供方覆盖模型设置、工作流配置、本地执行和成片导出；更多提供方可复用同一目录，无需修改助手循环。匹配的硬件产物和基础运行环境仍是前置条件。已审查的本地准备链路面向 Windows CPU 产物，不执行联网、驱动、自定义节点或模型安装。迁移包携带制作记录和媒体，不携带完整 Session 对话、系统镜像或凭据存储。

## 验证

Loader 组合覆盖能力注册、替换和释放、保留目标凭据的工作流恢复，以及在新 Session 中恢复项目后冷启动读取。迁移回归覆盖损坏片段与哈希、生命周期复用、并发重复写、取消、过期、有界准入和媒体引用重映射。独立并发测试进程验证私有文件系统资源。浏览器场景覆盖能力操作、声明式配置迁移、项目下载、空目标恢复和媒体预览。可选原生 ComfyUI 测试使用明确选择的已审查产物及无模型测试帧，不证明 AI 画质或推理性能。
