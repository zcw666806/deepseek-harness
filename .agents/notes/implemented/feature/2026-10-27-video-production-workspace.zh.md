# Agent Note: Session 拥有的视频制作项目

Status: implemented

[English](2026-10-27-video-production-workspace.md) | 中文

## 问题

生成的视频附件不能保存制作计划。作者需要可复用的角色和场景参考、可编辑镜头、生成历史、明确的成片顺序，以及预览和导出所选结果的方式。重试失败不能覆盖已采用镜头，重启后也不能静默重新提交付费请求。

## 决策

[video-production 服务](../../../../packages/video/video-production/README.zh.md)通过既有存储领域提供方为每个 Session 拥有一个带修订号的项目。记录绑定 Session 创建时间，变更串行执行，生成和导出尝试持续保留，恢复时将遗留运行中尝试标为中断。模型工具将完整项目作为已记录输出返回；浏览器编辑通过这些已记录读取进入模型上下文。[工作台 UI](../../../../packages/client/ui-video-production/README.zh.md)消费同一组操作。画布位置与成片顺序是分开的值。

浏览器使用固定版本的 [React Flow](https://reactflow.dev/learn) 呈现参考素材、提示词、生成器、已记录视频、成片编排与已渲染成片。节点与连线从制作记录派生。可编辑参考边修改 `assetIds`，视频采用边修改 `selectedVersionId`。镜头归属边保持固定。坐标、视口和选区属于浏览器视图存储；不持久保存另一套执行图或任务引擎。当前计划变化时，历史视频仍保留冻结输入，历史成片仍保留记录的源版本身份。

[持久批次决策](2026-11-03-production-workflow-controls-and-durable-batches.zh.md)拥有持久化的 Host 执行与恢复。批量生成捕获已保存输入，再串行派发独立操作。提供方服务在 Session 变更队列内、创建尝试或调用生成器之前检查 `onlyIfMissing`，因此并发批量会跳过先前排队请求已经完成的镜头。显式单镜头重试仍会生成新版本。失败和取消停止尚未启动的批量工作，保留已完成版本。

pi-ai 适配器注册由 effect 拥有的生成提供方。请求保留镜头的参考图顺序，仅对支持的模型使用原生参考图参数。提供方返回持久附件、响应取消，并在卸载时等待工作完全退出。[生成路由决策](../bug-fix/2026-10-19-video-generation-routing.zh.md)继续有效：视频目标不是对话模型。

可选的 [ComfyUI 适配器](../../../../packages/video/video-comfyui/README.zh.md)通过同一提供方注册表贡献运维配置的 API 格式工作流，默认处于休眠状态。不可变模板修订与显式标量绑定决定支持的时长、尺寸、有序参考图及选中的输出节点。每次尝试拥有 UUID、私有上传与输出目录，以及不重试的单次提交。服务端输出目录使用平台相关的路径分隔符；适配器先统一分隔符，再核对相对路径组件和本次操作目录归属。取消使用服务器按任务原子操作的端点和独立清理预算；远端终止不确定时携带任务标识报告。本地中止不能证明远端执行已经停止。适配器不安装 ComfyUI，也不下载模型或自定义节点。

生成目标是提供方拥有的当前生成器与模型组合及其限制描述。请求在记录尝试前恰好解析一个当前目标。新版本冻结生成器标识、名称和提供时的配置修订；缺少来源信息的历史版本保留为未知。浏览器选择应用于下一次单镜头或批量操作，不保存为镜头设置。移除选中的目标后，需要明确选择替代目标。

媒体读取核对附件属于项目，或属于所指定 Session 中记录的成功生成。有上限的编码分块避免整段视频占据单个 RPC 帧。成片导出接收选中的不可变镜头引用，使用受管理 FFmpeg/FFprobe 子进程、固定参数和私有临时文件，统一视频规格、保留音频并按需补充静音。视频 `fps` 滤镜在编码前建立帧率。已编码画面的实测时长明确限制独立音轨封装操作；仅依赖编码缓冲和 `-shortest` 会让音轨超出较短片段，并在片段之间引入空隙。画面只编码一次，在音轨封装期间直接复制。源时间戳归零，源解复用器固定，协议仅允许本地文件与管道，渲染器环境移除 `FFREPORT`。服务不暴露任意渲染命令，也不安装可执行文件。

[Toonflow 固定版本的视频节点与画布实现](https://github.com/HBAI-Ltd/Toonflow-app/tree/af6e884c3d8cda353acaf8ef13aea8ea754a4afd)为可复用参考、明确媒体版本和共享制作画布提供设计证据。其应用、插件、运行时和依赖均未导入。[Qywork 采用决策](2026-10-19-qywork-capability-adoption.zh.md)保留独立有效的资源、工作流和文件系统决策。

## 考虑过的替代方案

**导入完整外部创作应用。** 其运行时、存储、凭据和任务所有权会与既有 Harness 服务竞争。项目通过自身扩展采用已经核实的行为。

**把浏览器内画板作为制作状态。** 刷新、模型工具和成片导出会对所选版本与镜头顺序产生分歧。这些事实由持久服务拥有；UI 拥有当前选择和缩放。

**自建另一套节点编辑框架或导入图执行引擎。** 端口交互、视口导航、选择与节点测量由受维护的呈现组件提供。项目拥有这些交互的制作含义，并根据既有项目操作校验连接。通用图执行器会为生成和取消引入另一份权威状态。

**把所有参考图片当作首帧。** 首帧生成与角色、场景参考生成的提供方语义不同。不支持的参考组合会在付费请求前失败。

**暴露任意 FFmpeg 参数。** 滤镜表达式和间接文件输入可以执行简单输入白名单之外的 I/O。固定渲染操作提供所需导出，无须授予通用执行能力。

## 后果

作者可以组织和单独重生成镜头，保留已采用结果，再按明确顺序导出选中版本。参考一致性仍取决于配置的模型。每个 Session 拥有一个项目；共享、fork 继承、转场、语音合成和音乐混音需要独立操作。已采用片段保留非破坏性裁切、音量和定时字幕。单次生成与导出调用等待完成；持久批次在明确继续后仅恢复尚未提交的镜头。实际导出要求宿主本地 FFmpeg 和 FFprobe。

## 验证

文件系统逃逸 fixture 使用目录链接，在 Windows 上使用 junction，因此无须文件符号链接权限仍可验证真实路径拒绝。验证会先移除自己拥有的目录链接，再删除临时根目录。

协议、Loader 和 UI 测试覆盖参考顺序、取消和卸载、失败重试、Session 隔离、修订冲突、恢复、有上限媒体读取、Blob 生命周期、成片顺序与渲染器清理。手工编写的[制作快照](../../../../snapshots/session/video-production/snapshot.yml)通过随附 headless profile 回放双镜头计划，并比较持久工具输出。其响应是录制测试输入，不是真实模型画质或付费生成演示。显式启用的[真实成片测试](../../../../apps/web/tests/video-film-export.e2e.ts)使用明确指定的 FFmpeg 程序创建不同尺寸和帧率的本地片段，其中一段音轨较短、另一段无音轨，再验证真实 MP4 编码、时长、浏览器播放、下载字节一致，以及渲染器失败后保留上一成片。合成测试片段不验证 AI 输出质量。

[Web 规划快照](../../../../snapshots/web/video-workflow/snapshot.yml)拥有最小角色提示词、单个项目工具与明确声明的完整访问权限预设。它通过 Web Session API 执行已记录计划，将持久工具元数据与项目比较，并渲染所得工作流节点。独立的[浏览器工作流测试](../../../../apps/web/tests/video-production.e2e.ts)使用常规 Web 组合，验证原生端口连接、参考顺序、批量生成、断连重连、选区删除、导航、可播放测试媒体与下载。参考连线几何和版本化视图偏好有针对性回归；采用新视图格式不会替换 Host 项目数据。

显式启用的 [ComfyUI 诊断](../../../../apps/web/tests/video-comfyui.e2e.ts)通过随附 Web 组合使用明确指定的本机服务和已批准渲染器。原生黑帧经过真实 ComfyUI 提供方、持久生成版本、FFmpeg 导出、附件存储及授权媒体读取。该验证检查本地协议与编码链路，不下载模型，也不声称完成 AI 推理。
