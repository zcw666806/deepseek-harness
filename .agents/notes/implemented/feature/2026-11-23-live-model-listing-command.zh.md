# Agent Note: 用用户命令查询实时模型列表

Status: implemented

[English](2026-11-23-live-model-listing-command.md) | 中文

## 问题

用户问已保存的 API Key 可以访问哪些模型时，助手可能要经过多步推理和工具调用才返回列表。已配置的模型选择器以及适配器内置目录描述路由和模型元数据。两者都无法反映已保存连接此刻会返回什么。

## 决策

启用用户命令的组合中，[会话控制器](../../../../packages/api/session-controller/README.zh.md)注册 `/models`。只有所有者可以查询该会话下一次请求所选的提供方。[LLM 服务](../../../../packages/llm/llm/README.zh.md)为凭据解析和列表查询设定一个总时限，适配器使用已保存的端点和认证方式。结果进入用户命令日志。

## 考虑的其他方案

**调用面向模型的工具或 Shell。** 两种路径都可能为确定性查询增加模型轮次。Shell 也缺少适配器的路由和凭据解析。

**返回选择器目录。** 内置或本地配置的列表可能和提供方的响应不同，因此命令返回实时列表或明确的失败。

## 后果

支持的提供方每条命令收到一次目录查询。调用方能区分空列表、拒绝和超时。返回的 ID 反映提供方公布的列表，实际推理权限需要另行验证。
